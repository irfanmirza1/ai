# Munchlings: Flow Prompts for Every Shot (Episodes 1–3)

Every 🎬 FLOW shot from `episodes-1-3.md`, ready to paste into **Flow → Ingredients to Video**. The shot numbers match the scripts.

**How to use this file**
1. Add the **ingredients** in the order listed (at most 3). The main character always goes first.
2. Paste the prompt, then replace `[STYLE LOCK]` with the style line from `character-guide.md` (STEP 0).
3. Test on **Veo 3.1 Lite**, 8 seconds. When it looks right, run it again on **Fast**.
4. Save the clip as the file name shown, in `03_episodes/EPxx…/clips/`.

**Ingredient names** (from `character-guide.md`)

| Short name | File |
|---|---|
| BOB, COCO, TIM, PETE, KAI | `NAME_hero.png` |
| GROUP | the 5-character group image (STEP 2) |
| KITCHEN, FRIDGE, LUNCHBOX | `garden_kitchen.png`, `fridge_world.png`, `lunchbox.png` |
| PK-MARKET | `pakistan_market.png` (new set for Episode 3, prompt in `episodes-1-3.md`) |

**Credit budget:** 27 clips in total. With 2 Lite tests and 1 Fast final each, that's about 27 × (10 + 10 + 20) = **about 1,080 credits: one month of AI Pro for all three episodes.** Make the 2 shared clips first, because every episode uses them.

**Tips when a clip goes wrong**
- A character changes shape or colour: remove the prop ingredient and describe the prop in words instead.
- Two characters merge into one: make it a wide shot, and say "standing apart, side by side".
- Someone talks anyway: mute the clip in the edit. Only keep Flow's music and sound effects.
