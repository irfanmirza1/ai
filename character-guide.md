# Veggie Crew: Character Guide and Flow Prompts

The prompts are ready to paste. Do the steps in order.

---

## STEP 0: Style lock (paste at the END of every prompt)

```
Style: soft 3D animated preschool series, rounded chunky shapes, big glossy expressive eyes with white highlights, small simple mouth, smooth clay-like matte textures, bright warm pastel colors, soft studio lighting, gentle shadows, clean and cute, friendly for young children. No text, no logos, no watermark.
```

**Rules**
- Never change the style line. It's what makes every episode look like the same show.
- Every character has **stubby arms and small round feet and wears no clothes**, except the one prop listed for them.

---

## STEP 1: Make each character (Flow, image mode)

For each character:
1. Paste their **Sheet prompt**.
2. Generate 4 images and pick the best one.
3. Save it as `NAME_sheet.png`.
4. Then run their **Hero frame prompt**, with the sheet added as a reference image. Save that as `NAME_hero.png`.

The **hero frame** is what you'll use as the "ingredient" in Flow and as the photo in Jogg.

## STEP 4: Video prompts (Flow → "Ingredients to Video")

**Ingredients order:**
1. Character hero frame
2. Set image
3. Prop (optional)

Put the main character first. You can add at most 3 ingredients.

**Formula**
```
[Shot type] of [CHARACTER from reference] [doing ONE simple action] in [SET from reference]. [Camera move]. [Mood]. Audio: soft background music and [sound effects] only, no talking, no voices.
[STYLE LOCK]
```

Always write **"no talking, no voices"**. The voices come from Jogg, so every character sounds the same in every episode.

**5 ready examples**
```
Medium shot of Broccoli Bob from reference walking sadly across the Garden Kitchen counter, kicking a pea. Slow camera follow. Gentle sad mood. Audio: soft piano, small footsteps, no talking, no voices.
[STYLE LOCK]
```
```
Wide shot of Carrot Coco from reference running excitedly through Fridge World shelves, pointing ahead. Camera tracks alongside her. Adventurous mood. Audio: playful music, quick footsteps, no talking, no voices.
[STYLE LOCK]
```
```
Close-up of Tomato Tim from reference slipping on a lettuce leaf and rolling like a ball, then popping back up smiling. Static camera. Funny mood. Audio: cartoon boing and rolling sounds, no talking, no voices.
[STYLE LOCK]
```
```
Medium shot of Potato Pete from reference stirring a small pot of green soup on the Garden Kitchen stove with a wooden spoon, steam rising. Slow push-in. Warm cozy mood. Audio: bubbling, gentle music, no talking, no voices.
[STYLE LOCK]
```
```
Wide shot of Corny from reference dancing happily on the kitchen table, arms up, spinning. Camera circles slowly. Joyful party mood. Audio: upbeat kids music, claps, no talking, no voices.
[STYLE LOCK]
```

**Credit tips**
- Test every new prompt on **Veo 3.1 Lite** (10 credits).
- Re-run the good ones on **Fast** (20 credits).
- Use **Quality** (100 credits) only for thumbnail shots.
- Use **8-second** clips with **one action per clip**. Several actions in one clip is how characters break.

## STEP 5: Talking shots in Jogg

1. **Make the photo:** in Flow, create a "talking frame" for each character:
   ```
   [NAME] from reference, head and upper body, facing camera, mouth closed, neutral happy expression, [SET] softly blurred behind.
   [STYLE LOCK]
   ```
2. **Upload** that photo to Jogg as a **photo avatar / talking photo**.
3. **Pick the voice** from the list above. **Write down its exact name** below and never change it.
4. **Keep lines short:** 1–2 sentences per clip (under 10 seconds). Short clips give cleaner lip sync.
